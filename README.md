# Căn chỉnh Shim – Rim Face

Trường Cao đẳng Dầu khí (PV College) – Người viết ứng dụng: Giảng viên Lê Duy Nam

Tính shim chân motor khi căn chỉnh đồng tâm Rim – Face (bơm Ebara 100×80 FSJA).

- iPhone: mở https://leduynampvmtc-spec.github.io/can-chinh-shim/ bằng Safari > Chia sẻ > Thêm vào MH chính.
- Android: tải file .apk trong mục Releases.
- Windows: tải file .exe trong mục Releases (chạy trực tiếp, không cần cài).
