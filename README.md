# Căn chỉnh Shim – PV College

Ứng dụng tính shim chân motor khi căn chỉnh đồng tâm Rim – Face (bơm Ebara 100×80 FSJA).

**Người tạo: Lê Duy Nam – Khoa Cơ khí, Trường Cao đẳng Dầu khí (PV College)**

- `android/` – ứng dụng Android (file .apk)
- `windows/` – ứng dụng Windows (file .exe chạy trực tiếp)
- `web/index.html` – bản web, dùng cho iPhone và mọi trình duyệt

Mỗi lần đẩy code lên, GitHub Actions tự build và đăng file tải về trong mục **Releases**.
